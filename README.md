# THE DAY — A Story Worth Celebrating

Интерактивное свадебное приглашение: один непрерывный фильм, которым гость управляет прокруткой.
React, TypeScript, Vite, GSAP + ScrollTrigger, Lenis, Supabase.

## Что понадобится

- [Node.js](https://nodejs.org) 22 или новее и npm.
- Для приёма ответов гостей — бесплатный проект на [supabase.com](https://supabase.com). Без него сайт работает, но форма честно сообщает, что ответ не сохранён.
- Python 3 — только если вы заново обрабатываете фотографии.

## Установка и запуск

```bash
git clone <адрес-репозитория> the-day
```

```bash
cd the-day
```

```bash
npm ci
```

```bash
npm run dev
```

Откройте http://localhost:5173. Конверт показывается при первом визите, показать его снова можно по адресу `http://localhost:5173/?replay=1`. На телефоне в той же сети откройте адрес `Network`, который напечатает Vite.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Запускает локальный предпросмотр |
| `npm run build` | Проверяет типы и собирает сайт в `dist` |
| `npm run preview` | Показывает готовую сборку |
| `npm run typecheck` | Проверяет только типы |
| `npm test` | Запускает тесты сервера RSVP и вспомогательных функций |

## Секреты

В репозиторий не попадают `.env` и `supabase/.env`: в них хранятся ваши значения. В Git лежат только шаблоны `.env.example` и `supabase/.env.example`. Ключ `service_role` никогда не указывается в файлах с префиксом `VITE_`: такие значения видны в браузере.

## Что и где менять

Весь контент находится в **`src/config/wedding.ts`**: имена, дата, расписание, площадка, координаты, палитра, тексты, фото, музыка.
Код анимаций трогать не нужно. Когда всё заменено на настоящее, поставьте `isDemo: false`.

| Что | Где |
| --- | --- |
| Площадка | `location.name`, `address`, `coordinates`. Пока адрес и координаты пусты, кнопки маршрута нет |
| Карта для маршрута | `location.mapProvider`: `yandex` или `google` |
| Этапы дня | `timeline.items`, поле `kind` выбирает микроанимацию: `gather`, `ceremony`, `dinner`, `dance`, `party` |
| Музыка | `music.src`: путь к лицензированному файлу в `public/assets/audio`. `null` — эмбиент, который синтезируется в браузере |
| Скорость фильма | `PACE_DESKTOP` и `PACE_MOBILE` в `src/animations/film.ts`. Меньше значение — быстрее |

## Фотографии

Сейчас на сайте стоковые снимки с Unsplash: источники, авторы и лицензия указаны в [CREDITS.md](public/assets/CREDITS.md). Это временные фото с чужими людьми: перед отправкой гостям замените их снимками пары.

Все фото проходят через `scripts/prepare-photos.py`: кадрирование, единое тонирование Editorial Black, версии для телефона, WebP. Для вашей фотографии замените источник в `PHOTOS` и запустите скрипт (установка описана в его начале).

| Сцена | Что нужно |
| --- | --- |
| История | Одна горизонтальная фотография пары, лица близко друг к другу. Скрипт разрежет её по шву (`HERO_SEAM`), вырежет людей и создаст подложку без них |
| Дата | Снимок со светлыми крупными формами: он виден сквозь цифры |
| Ужин, танец, вечеринка | `timeline.items[].image` в конфиге |
| Площадка | Горизонтальный снимок, скрипт сделает вертикальную версию |
| Образы | Наряды в цветах палитры. Цвет сохраняется |

Как устроена глубина в сцене 02: подложка без людей → имя за людьми → вырезанные люди → имя перед людьми. Слои приближаются с разной скоростью, а масштаб всегда равномерный, поэтому лица не искажаются. Если подложки или вырезки нет, показывается целое фото, и композиция не ломается. Вырезку обязательно проверьте глазами на контрастном фоне.

## Как устроена анимация

- **Единый таймлайн** (`src/animations/film.ts`). Сцены 02–06 и заголовок 07 живут на одной закреплённой сцене и управляются одним GSAP-таймлайном. Состояние зависит только от позиции прокрутки, поэтому назад всё проигрывается точно так же, как вперёд.
- **Закрепление через `position: sticky`**, а не через pin ScrollTrigger. На iOS так нет дрожания и конфликта с Lenis.
- **Золотая нить** (`src/animations/thread.ts`). Одна линия на весь фильм: форма считается из ключевых форм и текущего времени.
- **Цепочка переходов.** Карточка из конверта становится фоном истории → кадр пары остаётся внутри цифры «20» → новый снимок проявляется в цифрах и разъезжается створками по линии расписания → линия складывается в арку площадки → снимок сжимается и переворачивается в первую карточку палитры → стопка переворачивается в лист приглашения.
- **Глубина в истории.** Подложка без людей → гигантские имена → вырезанные люди. Фон движется медленнее рамок, люди растут быстрее фона. Масштаб всегда равномерный, лица не искажаются.
- **Маска даты** — `mix-blend-mode: multiply`: браузер смешивает готовые слои и не перерисовывает фото на каждом кадре.
- **Конверт и письмо** — CSS 3D с явным порядком слоёв. Клапан из двух сегментов гнётся по линии сгиба.
- **WebGL и Three.js не подключены намеренно.** Все эффекты решаются средствами GPU в браузере: это легче и надёжнее в Safari и браузерах мессенджеров.
- **Телефон — своя режиссура.** Карточки сходятся по вертикали, конверт вертикальный, дата в три строки, расписание вертикальное, снимков образов по бокам нет, прокрутка короче. На касание Lenis не влияет: прокрутка остаётся нативной.
- `prefers-reduced-motion` отключает фильм: всё содержимое идёт обычной страницей.

## Подключение RSVP (нужны ваши действия)

Без этого шага форма честно сообщает, что ответ не сохранён.

1. Создайте проект на [supabase.com](https://supabase.com).
2. Войдите и привяжите проект (`project-ref` есть в адресе панели):

   ```bash
   npx supabase login
   npx supabase link --project-ref ВАШ_REF
   ```

3. Создайте таблицы:

   ```bash
   npx supabase db push
   ```

4. Задайте секреты: скопируйте `supabase/.env.example` в `supabase/.env`, заполните значения и загрузите. В `RSVP_ALLOWED_ORIGINS` обязательно укажите адрес сайта.

   ```bash
   npx supabase secrets set --env-file supabase/.env
   ```

5. Опубликуйте функции:

   ```bash
   npx supabase functions deploy submit-rsvp --no-verify-jwt
   npx supabase functions deploy rsvp-admin --no-verify-jwt
   ```

6. Скопируйте `.env.example` в `.env` и укажите `VITE_RSVP_ENDPOINT=https://ВАШ_REF.supabase.co/functions/v1`.

Ни одного ключа Supabase в браузере нет. Адрес функций не секрет, а `service_role` доступен только функциям.

### Защита

RLS без единой политики и отозванные права у `anon` и `authenticated`; подписанный токен формы с минимальным временем заполнения; ловушка для ботов; лимиты 12 отправок в час с адреса и 300 в час всего; проверка домена; один ответ на имя; идемпотентный повтор при обрыве сети; проверка числа гостей на сервере.

Если придёт волна спама с множества адресов, сработает общий лимит, но он остановит и настоящих гостей. На этот случай можно добавить капчу (например, Cloudflare Turnstile).

### Просмотр ответов

Страница `/organizer.html`, пароль — значение `RSVP_ORGANIZER_TOKEN`. Есть итоги и выгрузка CSV. Ещё ответы видны в панели Supabase: Table Editor → `rsvp_responses`.

### Персональные ссылки (по желанию)

Добавьте строку в панели Supabase, в таблицу `rsvp_invites` (код из 6–64 символов, имя, лимит гостей), и отправьте ссылку `https://ваш-сайт/?i=КОД`. Гость увидит своё имя на первом экране, а сервер применит его лимит.

## Публикация

```bash
npm run build
```

Папка `dist` — обычная статика: подойдут Vercel, Netlify, Cloudflare Pages или любой хостинг. Задайте там `VITE_RSVP_ENDPOINT`, а адрес сайта добавьте в `RSVP_ALLOWED_ORIGINS`.

## Проверки

```bash
npm run typecheck
```

```bash
npm test
```

Тестовые значения в `tests/` и `scripts/local-rsvp-server.mjs` работают только локально и не являются настоящими ключами. Тесты выполняют настоящую SQL-миграцию на встроенном Postgres (PGlite). Форму можно проверить локально без аккаунта Supabase: `node scripts/local-rsvp-server.mjs`, затем `VITE_RSVP_ENDPOINT=http://localhost:54399 npm run dev`. Этот сервер только для проверки: данные хранятся в памяти.
